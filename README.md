# lab4 — сайт авторизации

Небольшое веб-приложение с регистрацией и входом в аккаунт. После входа открывается страница пользователя с возможностью выйти из аккаунта.

## Возможности

- Регистрация и вход по email и паролю
- Проверка формата email и надёжности пароля
- Проверка, зарегистрирован ли email
- Сессии и функция «Запомнить меня»

Пароли хранятся в виде хешей (scrypt). Пользователи и сессии хранятся в базе данных PostgreSQL.

## GET, POST и cookies

Формы регистрации и входа отправляют данные методом `POST`. Сервер проверяет их и, при успешном входе, создаёт сессию и перенаправляет пользователя в аккаунт.

Метод `GET` используется для загрузки страниц, проверки доступности email (`/api/check-email`), получения данных текущей сессии (`/api/me`) и выхода из аккаунта (`/logout`).

Для авторизации используются cookies: `oa_session` хранит токен сессии, `oa_remember_login` отмечает вход с опцией «Запомнить меня», а `oa_remember_email` сохраняет email для следующего входа. Токен сессии хранится в cookie с флагом `HttpOnly`; срок действия сессии — до 24 часов или до 30 дней при выборе «Запомнить меня».

## Технологии

React 18 + Vite (интерфейс), CSS, сервер на Node.js, база данных PostgreSQL (драйвер `pg`).

## База данных

Таблицы создаются автоматически при запуске сервера из `db/schema.sql`:

- `users` — `id` (UUID), `name`, `email` (уникален без учёта регистра), `password_hash`, `created_at`
- `sessions` — `token_hash` (sha256 токена из cookie), `user_id` → `users`, `expires_at`, `created_at`

Просроченные сессии удаляются при старте сервера. Повторная регистрация одного email защищена уникальным индексом, поэтому даже одновременные запросы не создадут дубликат.

## Структура

```
index.html, dashboard.html   точки входа Vite (две страницы)

public/favicon.svg           статические файлы
db/schema.sql                схема PostgreSQL
db/index.js                  подключение (pg.Pool) и создание таблиц
scripts/import-json.js       разовый перенос пользователей из data/users.json
server.js                    API и раздача собранного сайта из dist/
```

## Запуск

1. Установите [Node.js](https://nodejs.org) 22+ и [PostgreSQL](https://www.postgresql.org/download/).
2. Создайте базу данных (пароль — тот, что задали при установке PostgreSQL):

   ```bash
   psql -U postgres -c "CREATE DATABASE lab4;"
   ```

3. Скопируйте `.env.example` в `.env` и укажите свой пароль в `DATABASE_URL`:

   ```
   DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/lab4
   ```

4. В папке проекта:

   ```bash
   npm install
   npm run build   # собирает React-интерфейс в папку dist
   npm start       # запускает сервер
   ```

Откройте в браузере http://localhost:8000.

Чтобы перенести пользователей из старой версии (`data/users.json`), один раз выполните `npm run import-json`. Сессии не переносятся — нужно просто войти заново.

## Режим разработки (hot reload)

Одной командой запускаются и сервер (:8000), и Vite (:5173):

```bash
npm run dev
```

Откройте http://localhost:5173. Запросы к API Vite сам проксирует на сервер. PostgreSQL при этом должен быть запущен.

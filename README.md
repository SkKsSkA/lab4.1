## Запуск

1. Установите [Node.js](https://nodejs.org) 22+ и [PostgreSQL](https://www.postgresql.org/download/).
2. Создайте базу данных (пароль — тот, что задали при установке PostgreSQL):

```bash
   psql -U postgres -c "CREATE DATABASE lab4;"
```

3. Скопируйте `.env.example` в `.env` и укажите свой пароль в `DATABASE_URL`:

```
   DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/lab4
```

4. Установите зависимости (один раз) в папке проекта:

```bash
   npm install
```

### Запуск для разработки (рекомендуется)

Одна команда запускает сразу и сервер (:8000), и Vite (:5173), поэтому отдельные терминалы для них не нужны:

```bash
npm run dev
```

Откройте в браузере http://localhost:5173. Запросы к API Vite сам проксирует на сервер, а изменения в `src/` применяются мгновенно (hot reload). PostgreSQL при этом должен быть запущен. Остановка обоих процессов — `Ctrl+C`.

### Запуск готового сайта

Нужен, когда не требуется hot reload (например, для сдачи или показа). Работает только сервер:

```bash
npm run build   # собирает React-интерфейс в папку dist
npm start       # запускает сервер
```

Откройте в браузере http://localhost:8000. После любых изменений в `src/` перед `npm start` нужно снова выполнить `npm run build`.

### Перенос старых пользователей

Чтобы перенести пользователей из старой версии (`data/users.json`), один раз выполните `npm run import-json`. Сессии не переносятся — нужно просто войти заново.
